# Paper Kite

A cozy one-button arcade game in a cut-paper style. Hold to climb, let go to glide, catch ribbons and golden bells, and dodge crows and storm clouds as the sky turns from dawn to night.

**Play it:** open the GitHub Pages link for this repo (Settings → Pages).

## Controls
- Hold the mouse button, tap, or hold Space, ↑ or W to climb
- Let go to glide
- Enter or Space starts the game, P or Esc pauses it, and R restarts it

## About
The whole game is one self-contained `index.html` file: HTML5 Canvas, sounds generated in the browser, no images and no libraries. It was built from a single AI prompt.
